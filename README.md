# AI-Powered Contract Intelligence & Risk Scoring (NLP)

## 📋 Overview
This project uses Natural Language Processing (NLP) to analyze legal contracts, 
extract key clauses, and assign risk scores automatically. It helps identify 
potentially risky terms in contracts without manual review.

## 🎯 Features
- Extracts key clauses (payment terms, termination, liability, etc.)
- Identifies risky or non-standard clauses
- Assigns an overall risk score to each contract
- Generates a summary report for quick review
